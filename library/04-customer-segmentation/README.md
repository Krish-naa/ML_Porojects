# Customer Segmentation with K-Means

Group customers into segments based on annual income and spending score — a common
marketing analytics task — using unsupervised K-Means clustering.

## Approach
- Data: synthetic customers generated with NumPy (no external files).
- Scale features, run K-Means, evaluate cluster quality with the silhouette score.
- Print an interpretable profile for each segment.

## Run
```bash
pip install -r requirements.txt
python main.py
```

## Concepts
Unsupervised learning, clustering, feature scaling, silhouette score.
