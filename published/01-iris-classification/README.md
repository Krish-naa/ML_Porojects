# Iris Flower Classification

Predict the species of an iris flower (setosa, versicolor, virginica) from four
measurements — sepal length, sepal width, petal length, petal width.

## Approach
- Dataset: the classic Iris dataset (built into scikit-learn).
- Model: Random Forest classifier.
- Split into train/test, evaluate with accuracy and a per-class report, and print feature importances.

## Run
```bash
pip install -r requirements.txt
python main.py
```

## Concepts
Supervised classification, train/test split, ensemble methods, feature importance.
